# ビジュアル調整パス

添付のアニメ背景で全25枚を見比べ、初期値と5プリセットを調整した。
狙いは、構造変形を一目で読める強さを残しながら、人物の輪郭と空の色を破綻させないこと。

- 通常: 中程度の変化範囲と16回探索。髪・肩・屋根の輪郭に構造が出る。
- 弱め・自然: 変化範囲と強さを落とし、カット途中の常用を想定。
- 強い: 明確な変形と色相変化。人物を識別できる範囲に制限。
- 極端・実験: 大きい範囲・低しきい値・高い色相変化。意図的に実験的。
- 映像向け: 反復と範囲を抑え、連続カットで使いやすいバランス。

共通の仕上げで、暗部はわずかに青、明部はごく小さく暖色へ寄せた。色相回転だけで全体が緑やマゼンタへ転ぶのを抑え、元の人物色を残しながら構造部分の色変化を見せる。

実際の比較画像は `outputs` から生成した25枚を使用。`parameters.json` に各PNGの値を保存している。
